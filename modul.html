6. Praktikum

Lab A — ESP32 Blink

#define LED_PIN 2

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);

  digitalWrite(LED_PIN, LOW);
  delay(1000);
}

  • Upload firmware berhasil.
  • LED berkedip normal.
  • Memahami setup() dan loop().

9. Dashboard Node-RED

[mqtt in]
    ↓
[json]
    ↓
[function]
    ↓
[ui_text / ui_gauge]

Install Node-RED

npm install -g --unsafe-perm node-red
node-red

Function Counter

let c = flow.get('counter') || 0;
c += 1;
flow.set('counter', c);

msg.payload = c;
return msg;

10. Eksperimen Bandwidth

❌ Mode Boros

Mengirim full image/video ke server.


100 kamera ≈ 72 GB/jam


Dampak:

  • Bandwidth besar
  • Storage mahal
  • Latensi tinggi

✅ Mode AIoT Ideal

Mengirim event JSON hasil AI. 


{
  "objects": {
    "person": 2
  }
}

Payload hanya ratusan byte.

Kesimpulan

AIoT ideal bukan berarti video tidak pernah dikirim, tetapi sistem lebih efisien jika inferensi dilakukan di edge dan jaringan hanya menerima metadata penting.

12. Troubleshooting

ESP32 Tidak Terdeteksi

Cek kabel USB data dan driver serial.

Upload Gagal

Tekan tombol BOOT saat upload.

MQTT Tidak Jalan

Cek broker, port 1883, dan topic.

Dashboard Tidak Update

Pastikan flow sudah deploy.

YOLO Lambat

Gunakan resolusi rendah atau video pendek.

Node-RED Error

Pastikan port 1880 tidak digunakan aplikasi lain.
